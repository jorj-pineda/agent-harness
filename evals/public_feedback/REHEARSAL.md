# Mandatory-mock rehearsal and first inputs

`evals.public_feedback_rehearsal.rehearse_feedback` runs the eight fixed comparison
cells through the shared evaluator and production Ollama serializer with an
internally constructed **mandatory HTTPX MockTransport**. There is no live transport
parameter, backend construction or live CLI. The selected endpoint remains in the
request, but the transport consumes it locally; no request is sent to that service.

The caller selects a replacement command environment, executable inventory and
dependency-file manifest with their hashes. Clean source revision and these pins
are checked before output allocation. Complete credential-free Settings and the
effective command environment are preserved, along with the selected inventories.
Source, Settings, inventory/dependency selections and captured evidence are checked
around requests and between cells. Unknown, dirty, invalid or drifting selections
refuse; occupied output paths are never reset. Hashes and path checks are bounded
observations, not complete import closure, authenticated identity or isolation.

## Canned workflow, real files and checks

Each cell has a fresh single-use arm-specific workspace. The canned native
responses perform four requests:

1. Read the implementation and selected visible test.
2. Write a synthetic implementation of the observed bool defect and run the check.
3. Observe that control passes or treatment fails, then write the known reference
   and run the check again.
4. Observe the passing check and finish.

The handler validates the actual offered tools and returned check exit codes.
Independent original acceptance grades the final artifact outside the workspace.
Both arms receive the scripted reference correction; this is not model reasoning,
evidence that feedback causes recovery, or a measured arm advantage. Reported token
counts are deliberately canned. No old artifact or acceptance criterion changes.

## Captured evidence and failure handling

The existing bounded native evidence transport saves all four request/response
pairs per cell. The first normalized request is captured before serialization;
tests verify complete native agreement with normalized messages/tools/options.
The mock handler binds the generated native payload bytes before archival checking.

Each cell's private evidence includes normalized first input, native payloads,
initial/final visible tests, final implementation, runtime configuration, result
and prepared/admitted receipts. These selected files are mode 0600; outer and
native containers use 0700. The consumed workspace retains its ordinary selected
file modes. The final index binds 20 selected private files per cell plus Settings,
environment, inventories and the aggregate report. Workspace pytest caches are
not part of that selected evidence set; this is not a complete filesystem archive.

Each result is saved before deciding whether to advance. A provider error, changed
source/evidence, unexpected workflow/check outcome, altered receipt/test or native
inventory mismatch stops later cells and preserves partial output. Adapters close
on exit. The success index is exclusive and written last, only after all eight
scripted reference artifacts complete and pass independent grading. Partial output
does not constitute a complete capture and cannot be retried in the same directory.

The first inputs name these **consumed rehearsal** workspace paths. They are not
fresh live candidate fixtures or admission authority. A future live preparation
needs distinct candidate paths and its own exact input selection/preservation.

`prepare_feedback_candidate` prepares the fixed eight-cell visible-check comparison
using an explicitly selected existing external Python interpreter and clean retained
source revision. It reuses the interpreter guard: the retained tree cannot contain
a local `.venv`, interpreter aliases cannot substitute for the selected environment,
and the running interpreter/prefix must remain outside that tree. No resolver,
installer, backend, parent receipt or inference is started.

The caller selects executable paths (including Python and the existing Ollama
binary), dependency files, an existing source model image and the replacement
command environment. These observations and source selection precede exclusive
output allocation. The destination cannot overlap selected inputs. Selected files
and distribution versions do not establish complete import/shared-library closure.

Preparation privately records runtime/dependency observations and makes a verified
image with the existing native copy helper. Mandatory-mock real-tool rehearsal
captures all eight arm-specific normalized/native first inputs. That consumed
capture is preserved unchanged before eight fresh unadmitted fixtures are staged
at the same absolute paths. The distinct feedback manifest binds the plan,
Settings/environment, capture/runtime/dependency/image/executable pins and paths.
Read-only preflight, interpreter and clean-source checks precede writing the
candidate manifest and preparation receipt.

Use independent named directories for candidate and rehearsal bundles. Their
first-input roots and fixtures remain separate. An occupied directory refuses;
there is no reset, rollback, cell replacement or retry. Failures after allocation
retain partial evidence and attempt withdrawal plus a failure record. A manifest
retained during a late receipt failure is withdrawn, not eligible for execution.
A secondary recording error is attached to the original exception.

The preparation receipt explicitly states no inference, no actual parent approval
and no verified import closure. Neither preparation nor scripted reference success
establishes model quality, current ownership or a resource lease. Existing public-
pilot/held-out formats, application defaults and closed cohorts remain unchanged.

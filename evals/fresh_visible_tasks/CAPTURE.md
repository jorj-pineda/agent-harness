# Mandatory-mock fresh-task input capture

`rehearse_fresh_inputs` prepares and consumes twelve new arm-specific cells through
shared `run_task`, real file/check tools and the production Ollama adapter. Generation
uses only an internally constructed `httpx.MockTransport`; there is no transport
injection or live-mode option. It does not start a backend or issue approval.

The fixed script writes the selected reference, runs the selected visible check
and finishes after observing its pass. Every cell has three native requests with
canned usage of 10 prompt/5 completion tokens each. These twelve scripted reference
successes establish mechanics, not model capability, recovery or feedback benefit.
The stronger and weak cells retain their exact selected initial tests and original
independent acceptance. They are fresh public development tasks, not held-out data.

The caller explicitly selects a replacement command environment, a private runtime
inventory and a selected dependency-file manifest by expected hashes. The source
revision must be clean. Source revision, effective settings, inventory/dependency
observations and already-preserved evidence bracket adapter requests and cells.
This records selected files and executable/distribution observations, not complete
import/shared-library closure, isolation, authenticated provenance or a launch lease.

Normalized first inputs and serialized native request/response/metadata are saved
alongside each initial/final visible test, final implementation, runtime config,
result and prepared/admitted fixture receipts. Native bytes must match the internal
transport observations. New result labels remain scripted. Success requires twelve
accepted/completed/verified reference rows, unchanged tests, exact final reference
bytes and all mock/native transports closed without request failure. The native
transport's close operation deliberately marks it unusable; request failure is
checked before close and closure is checked separately.

Outputs are private and exclusive. Each result precedes later cells. Drift, native
failure or cancellation stops dispatch and retains partial evidence plus a failure
marker. Success `index.json` is written last, never after failure. There is no
reset, retry or resume; even failed consumed cells are not candidate execution slots.
Primary exceptions remain primary if transport or failure-marker recording also fails.

Focused tests cover all twelve native/normalized serialization pairs, independent
reference acceptance, original visible-test retention, canned usage, private hash
bindings, occupied outputs, runtime/dependency refusal, native failure, preservation
drift, cancellation/closure and unexpected request refusal. Real HTTP transport
construction is forbidden in the success test with ambient proxy/key sentinels.
The settings capture excludes credentials; no credentials belong in caller-provided
command environments or selected artifacts.

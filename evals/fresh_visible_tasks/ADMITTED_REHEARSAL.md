# Reusable admitted mandatory-mock rehearsal

`rehearse_fresh_execution` creates and consumes only a new rehearsal bundle. It
first uses one-shot candidate preparation, then binds a synthetic parent fixture
to that exact manifest and zero freeze IDs. Its private fixture verifier accepts
only those selected objects. This simulation override is not actual approval;
there is no transport, provider or verifier injection and no live mode.

The existing guarded executor runs all twelve task/arm/repeat cells with separate
owned images/backends. Generation uses only the shared internal three-response
write/check/final mock, selecting each task's original reference implementation.
Real backend traffic is owned metadata, not model generation. Results precede
settlement and the shared executor stops on failure or cancellation. Any failure
after preparation withdraws the partial bundle without resetting consumed cells.
An existing bundle is refused before generating a synthetic fixture or launching.

Success is written last, only after twelve completed/accepted scripted results,
closed transports with exactly 36 mocked requests, finished ledger correspondence,
clean/unforced agreeing settlement, exact private native inventories and payload
hash correspondence to mock request/response bytes. The summary binds manifest,
preparation, report, session/cleanup and native evidence hashes. The descriptive
report retains all six pairs with benefit `not_assessed`.

Use a separate unused candidate for any future comparison; this API accepts no
existing candidate path for consumption. A synthetic affirmative receipt does not
authenticate a real freeze or user instruction. Native retained proof and full
candidate gates, followed by concrete freeze review and actual approval/fresh
launch checks, remain before real inference. Scripted reference success is not
model quality, recovery, held-out evidence or a release decision.
